# 通用数据质量规则

## 质量检查

检查字段类型、缺失、主键候选、重复、异常、时间范围和一行代表的对象。
将计算完整性、数据质量与业务正确性分别描述；完整查询不代表业务准确。
样本探查只反映样本；明确实际检查行数和范围，不用样本等级为全量背书。
不存在独立正确性检查时写“业务准确性未评估”，不默认 A 级或 100%。

## 加工边界

异常值默认保留并标记；需要剔除或填补时先确定业务规则与授权，再用平台提供的能力执行。
缺失值与零值区分，文本业务编号保留前导零，金额先确认单位与转换规则。
去重需要业务键和保留规则；重复记录可能是真实业务事件，不能全行去重后宣称质量提高。
每个实际变换记录操作、参数、前后行数和假设；未执行加工时不声称生成加工日志。
当前运行时没有清洗工具时说明缺口，不生成或执行任意 Python 脚本，不修改原始来源。

## 分析门禁

目标字段缺失、单位未知、混合粒度无法区分、结果截断等阻碍问题回答时，先说明并请求必要口径。
问题不影响目标统计时可继续，但将影响范围写进局限；不要用未经校准的等级代替具体问题。
报告中的每个关键数字都绑定真实查询结果，严重质量问题不能用漂亮报告掩盖。
