# PPT 生成

## 你要做什么

把**当前对话里已经完成并验证过**的分析，压缩成一组能讲清楚的幻灯片。

## 最重要的一条规则

# 复用当前对话的结论，不要重新取数。

报告类技能的第一原则在这里同样成立：数字必须和刚才的分析对得上。

## 分页建议

1. **封面**——主题、期间、数据范围。
2. **一句话结论**——这一页如果只留一句话，留哪句。
3. **核心指标页**——3–5 个 KPI，每个带同比/环比。
4. **变化与原因**——趋势图 + 归因结论。
5. **拆解**——按区域/品类/渠道展开。
6. **风险与机会**——需要关注什么。
7. **行动建议**——下一步做什么，谁负责。
8. **附录**——口径说明、数据范围。

## 硬性要求

- 一页一个观点。塞不下就拆页。
- 每页标题就是那句观点本身，不要写"数据分析"这种无信息的标题。
- 图表只保留支撑观点的部分。
- 不要出现工具名、SQL、内部对象名。
- 幻灯片数量控制在 8–15 页；内容少就少做，不要注水。
