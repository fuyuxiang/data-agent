# 数据可视化

## 你要做什么

为每个结论挑一张最合适的图，并给出一句能替代图的图注。

## 选型规则

| 要表达的关系 | 用什么图 |
| --- | --- |
| 随时间变化 | 折线图；只有几个点且要强调大小差异时用柱状图 |
| 类别之间比较大小 | 柱状图，按大小排序 |
| 构成占比 | 饼图（不超过 5 个扇区）/ 堆叠条形图（多于 5 个） |
| 两个变量的相关性 | 散点图 |
| 分布 | 直方图 / 箱线图 |
| 变化流向 | 瀑布图 |

## 执行顺序

1. 已经有结果数据就直接用；没有就先取数。
2. 不确定类型时调用 `select_chart`，它会基于数据形态给出建议。
3. `generate_chart` 生成图表。
4. 写图注：一句话说清这张图在说什么。

## 硬性要求

- 一张图只表达一件事。
- 类别超过 8 个时不要用饼图。
- 坐标轴要有单位；数值要格式化（万、亿、千分位）。
- 颜色用来区分含义，不要每个类别一个颜色。
- 不用 3D、不用双 Y 轴、不用装饰性渐变。
