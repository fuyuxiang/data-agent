# 预测分析

## 你要做什么

用历史数据推算未来，并诚实说明这个推算有多可靠。

## 执行顺序

1. 取足够长的历史序列。少于 12 个周期时，**先说明数据量不足**，
   最多给一个粗略趋势外推，并明确标注这不是可靠预测。
2. 调用 `run_analysis` 选择合适的时序方法。可选方法由平台审核提供，
   包括 ARIMA、SARIMA、Prophet、指数平滑等。
3. 检查序列特征：是否有明显季节性、是否有异常点、趋势是否稳定。
   这些直接决定该用哪种方法。
4. `validate_result` 校验后再输出。
5. 给出预测区间，不只给一个数。

## 输出要求

- 预测值 + 置信区间，区间是必需项。
- 写明用了多少历史数据、什么方法、什么粒度。
- 列出关键假设（季节性延续、无重大外部冲击等）。
- 主动说明不确定性：样本区间、可能失效的情形。
- 真实历史序列与预测序列在图上要能区分。
