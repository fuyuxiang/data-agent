# Excel 导出

## 你要做什么

把分析结果变成一张能继续被加工的表。

## 最重要的一条规则

# 导出的数字必须与当前分析一致。

用户已经看过结论了，导出的表如果对不上，信任就没了。

## 导出前确认

1. **范围**：导哪张表？全量明细还是汇总结果？用户没说清楚就问。
2. **粒度**：一行代表什么（订单？城市×月份？），写在表头说明里。
3. **字段**：只放用户需要的字段，不要把内部 ID、追踪字段倒出来。
4. **口径**：指标名称、时间范围写进说明页。

## 硬性要求

- 金额、数量保持数值类型，不要存成文本。
- 日期用统一格式，不要一部分是字符串一部分是日期。
- 超过十万行时先和用户确认是否抽样或分表。
- 导出完成后告诉用户文件存在哪里、包含什么。
