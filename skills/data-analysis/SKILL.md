# 数据分析

## 你要做什么

把一批业务数据讲清楚：趋势朝哪走、结构长什么样、谁在拉动、谁在拖后腿、有没有反常的点。

## 分析方法都在你内部

同比、环比、增长率、排名、占比、分组对比、集中度、波动率——这些都是本技能的
内部动作，**不要**为它们去调用其他技能，也不要因为"这只是个小动作"就跳过计算。

- 同比：与去年同期比较
- 环比：与上一个相邻周期比较
- 贡献度：某维度变化对整体变化的影响（pp 与 % 要分清）

## 执行顺序

1. `list_semantic_metrics` 确认正式指标，优先 `query_metric` 取数。
2. 没有指标时 `get_schema` + `query_data` 自己算。
3. 复杂统计（分布检验、聚类、回归等）用 `run_analysis`，它调用的是受控沙箱里的
   审核过的算法，不要自己写 Python 冒充分析。
4. 图表用 `generate_chart`；不确定类型时先 `select_chart`。
5. `validate_result` 通过后再下结论。

## 输出要求

- 结论先行：一句话说清"发生了什么"。
- 同比/环比必须标明基期，不能只写"增长 12%"。
- 结构分析给出占比，而不是只给绝对值。
- 发现异常点要单独指出，并说明判断依据。
- 区分"数据说明了什么"和"你推测的原因"，后者必须标记为推测。
