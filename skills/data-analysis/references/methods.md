# 通用分析方法

只读取当前问题需要的章节。字段、指标、单位与业务粒度必须来自已授权的实际结构和口径。

## 诊断与对比

先复现目标指标，再确认当前期、基期、时间边界、过滤条件与分组粒度一致。
先用一次合并查询取得总量与必要维度，结果不足时再下钻。连续两次同范围无数据就说明缺口，停止日期穷举。
增长率为 `(当前值 - 基期值) / 基期值`；基期为零时增长率不可定义，报告绝对变化。
负基期和极小基期不宜直接解释为经营改善或恶化，应同时给基期值与绝对变化。
比率的整体值用 `SUM(分子) / SUM(分母)`，不能直接平均各组比率；分母为零时返回空值并说明原因。
百分比变化与百分点变化分别为相对变化和比率差，不能混用。口径不一致时先补齐口径，不能硬做比较。

## 结构与异常

观察总量、分组规模和组内表现，区分结构变化与实际表现变化；不同粒度不能直接相加。
缺失值不是零；重复行不一定是错误，先核对业务主键。IQR 或标准差只发现统计异常，不能证明记录错误。
异常默认保留并标记，不擅自删除、填补或修改来源。抽样统计只描述样本，不能作为全量总量。
比较多组时同时报告效应大小、样本量与不确定性，不能只挑选最显著的结果。
图表按问题选型：时间变化用折线、排名用条形、结构用少量可加项的构成图；混合单位不能共享同一数轴。

## 执行与表达

大型数据库优先下推筛选、聚合、关联及窗口计算，只拉取有界结果。
复杂统计只能调用运行时已提供的审核方法；参考文档不是代码执行授权。
当前证据足够时停止探查；已有已核验结果生成报告时复用结果，不重新查询。
发现写成完整句：对象、时间、指标、变化与证据。推测就近标注，建议说明执行对象、范围与行动。
报告通过 submit_analysis_report 组织内容：指标绑定查询单元格，发现引用结果；推导数字先算到结果中。
置信度是解释性标签，必须附依据；没有独立质量评估时写“未评估”。
