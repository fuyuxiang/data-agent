# 通用变化分解

## 加总指标

对可加指标，组贡献为 `组当前值 - 组基期值`，组贡献加总应等于整体变化。
贡献占比为 `组变化 / 整体变化`；整体变化为零或很小时，以绝对贡献为主，不强行给百分比。
先统一两期分组全集；新增或消失组按真实记录补齐零总量，不能把未知值补成零。
用同一查询输出当前值、基期值、绝对变化和贡献占比，再验证加总误差。

## 量与单价

只有业务定义确实满足 `总量 = 数量 × 单价` 时才能使用量价分解。
使用对称分解：数量效应为 `(Q1-Q0)*(P0+P1)/2`，价格效应为 `(P1-P0)*(Q0+Q1)/2`。
两项之和精确等于 `P1*Q1-P0*Q0`，包括交互变化；分组单价须按实际数量加权。
没有数量和价格的真实证据时不能宣称已经检查量价原因。

## 比率的结构效应

整体比率 `R = SUM(w_i*r_i)`，权重由分母规模决定，权重和为一。
在两期均有可比定义的同一分组集合上：
结构效应 `SUM((w1-w0)*(r0+r1)/2)`；组内效应 `SUM((r1-r0)*(w0+w1)/2)`。
两项之和等于整体比率差，单位为百分点或比率单位。不能漏掉交互项，也不能对各组率直接求平均。
新增、消失或零分母组没有可比组内率时，先声明处理方法；不要猜测不存在的基期率。

## 归因边界

贡献分解解释观测到的变化如何组成，不自动证明因果。移除某组再重算只能做敏感性检查。
相关性、时间先后和统计显著性也不单独证明因果；推测需标注替代解释与待验证条件。
需要因果判断时明确实验设计、混杂控制与假设；运行时没有相应审核方法就说明能力与证据缺口。
输出已证实的贡献、可能的解释及建议行动，不强制凑出原因数量。
