# 上级参考工程审阅结论

## 它本质上是什么

参考工程不是单一的“自然语言转 SQL”程序，而是一个本地优先、可扩展的经营数据分析工作台。它用对话作为主入口，把数据接入、结构识别、SQL 执行、统计分析、图表、知识检索、任务、工作流、团队协作和报告交付串成一条连续链路。

主运行路径是：

```text
用户问题
  → 读取会话、数据源结构、知识与记忆
  → 模型推理并选择工具
  → 生成和校验只读 SQL
  → 执行查询 / 统计分析
  → 选择图表并生成结果
  → 流式返回阶段、证据与结论
  → 保存会话、任务、成果和审计信息
```

## 已实现的能力

### 1. 数据接入与工作区

- Excel、CSV 与多种 SQL 数据库。
- Google Sheets、HTTP API 和协作平台表格。
- 多数据源组合、表结构发现、数据预览和断开连接。
- 本地目录挂载、文件登记、工作区隔离、权限和快照恢复。

实现方式以统一数据源抽象承接不同读取器，再把文件型数据转为 Pandas/DuckDB 可查询表；关系库通过 SQLAlchemy 驱动访问。工作区元数据和数据文件分开保存。

### 2. 对话式分析

- 多轮会话、临时指令、上下文压缩与历史保存。
- OpenAI-Compatible 模型配置和会话级模型选择。
- 模型决定分析步骤并调用查询、统计、图表和导出工具。
- SSE 持续返回阶段、工具调用、结果和错误。

其核心是循环式智能体运行时：系统提示中注入数据结构与可用工具，模型返回工具调用，后端执行后把结果再次加入上下文，直至形成最终回答。长结果以成果文件或结果引用代替无限塞入上下文。

### 3. 数据质量与统计建模

- 缺失值、重复值、空白字符、缩尾和数据画像。
- 十分位分层、K-Means、A/B 检验、单变量筛选。
- 回归、逻辑回归、决策树、通用机器学习与神经网络。
- ARIMA、季节模型、多变量时间序列、趋势/节律模型和神经网络预测。

实现上以独立分析模块暴露参数定义、适用条件和结果结构，由工具注册表统一发现和调用；耗时任务可以交给 CPU/GPU 执行通道。

### 4. 图表与看板

- 覆盖比较、趋势、分布、关系、构成和地理等图表族。
- 根据字段类型、基数和分析意图选择图表。
- 保存图表、组合看板、刷新组件和导出独立 HTML。

参考工程的图表实现以 Python 图表模块生成独立结果；前端同时包含 ECharts/Plotly 运行时。图表选择规则与具体绘制代码分离。

### 5. 知识、记忆与 Skills

- 文档解析、切块、向量/全文检索和引用。
- 用户/工作空间范围的长期记忆。
- 可复用技能文件的发现、解析、注册和执行。

知识检索在回答前注入相关片段；记忆由独立存储管理并支持整理与归档；技能通过声明式元数据限制适用范围和参数。

### 6. 后台任务、工作流与协作

- 持久化任务状态、事件序列、取消和历史清理。
- 有向无环工作流、草稿/发布版本、审批、暂停、恢复和取消。
- 多角色分析团队、任务拆分、消息与计划状态。
- 条件 Hook 在生命周期事件发生时执行动作。

工作流不是简单脚本，而是带状态机的确定性执行器；每个节点记录输入、输出、状态和审批。团队协作在其上增加动态计划和角色上下文。

### 7. 交付、集成和运行保障

- Excel、Word、PowerPoint、图表与结果文件下载。
- MCP 服务发现与工具调用。
- 协作机器人、通知、远程计算节点和本地 GPU 探测。
- 身份、配额、生命周期清理、安全响应头和桌面打包。

## 参考工程的实现特点

优点：领域能力覆盖广；会话、任务和成果之间已经建立关联；对本地部署、长任务、取消、恢复和文件生命周期考虑较多；分析算法与图表种类丰富。

需要改进的地方：前端同时存在历史脚本、模块化脚本和 Vue 岛，状态与交互分散；部分能力以规划中或可选依赖形式存在；超大核心文件承担了过多职责；同一实体在文件、内存和 SQLite 间存在多套存储方式；产品内部术语和技术代号较多，增加维护与学习成本。

## 本工程采取的改进

1. 用 Vue 3 单一状态入口代替多套前端运行模式，所有页面共享工作空间、会话、数据源和任务状态。
2. 用统一事务记录仓库承接业务元数据，消息、审计和任务事件使用专门表，避免每个功能各建一套文件协议。
3. 把 Python 后端拆为 API、领域服务和基础设施三层；数据、分析、编排、交付和集成边界清晰。
4. 将只读 SQL 校验、凭据加密、非破坏性清洗、审批不可跳过和逻辑回收站设为默认规则。
5. 工作流执行器在恢复时重建已完成步骤上下文，失败会同步写入运行与任务两条状态链。
6. 多顾问协作真正并行执行，后台队列持续记录进度和可重放事件。
7. 模型不可用时保留本地确定性分析路径，使基础分析不依赖外部 API。
8. 图表采用前后端共享语义规范，查询结果、图表、看板和导出成果保持来源引用。
9. 增加标准 Cron 调度、SMTP 邮件、HTTP 与 stdio MCP、Google Sheets/协作表格等完整接入路径。
10. 使用自动化测试覆盖关键闭环，而不是只验证单个接口存在。
