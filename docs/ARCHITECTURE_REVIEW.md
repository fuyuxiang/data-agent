# 生产架构与安全验收记录

验收日期：2026-09-05

## 结论

当前版本已达到“单节点、受控内网或 HTTPS 反向代理后的生产候选版”标准。代码范围内已修复本次审查发现的多租户越权、匿名看板、任意目录挂载、SSRF/DNS 重绑定、命令子进程密钥泄漏、XML 外部实体、假刷新、无界任务队列、数据库非只读连接、弱口令派生、明文备份和依赖漏洞等阻断项。

这不等于无条件直接公网暴露。上线前仍必须按 `docs/PRODUCTION.md` 配置 HTTPS、三把独立密钥、可信 Host、出站和数据库白名单、只读数据库账号、SMTP 与模型凭据，并在目标环境执行恢复演练和业务 UAT。

## 已完成的生产化改造

- 身份与租户边界：新旧 API 统一验证登录、工作空间成员关系和角色；记录查询使用原子工作空间过滤，越权访问不暴露记录是否存在。
- Web 安全：生产会话开启 Secure/HttpOnly/SameSite，写请求验证 CSRF 和 Origin，CSP 使用每请求 nonce，JSON 脚本数据防止闭合注入，Draw.io 服务端目录不再发布。
- 出站边界：HTTP/MCP 请求执行域名白名单、DNS 地址校验、连接 IP 固定、跳转重验证和响应大小限制；数据库使用独立白名单。
- 执行边界：命令 Hook 默认关闭并强制可执行文件白名单；stdio MCP 不继承应用密钥；SSH 支持密码、私钥或 Agent，并强制固定主机密钥。
- 数据库：支持 SQLite、PostgreSQL、MySQL 和 SQL Server；表/视图发现保留 schema，用引号包裹标识符，连接池健康检查，会话只读、语句超时和 TLS 默认值按各驱动落地。
- 任务与调度：全局/租户队列上限、异常容量释放、启动孤儿任务恢复和优雅停止已实现；Cron 支持范围和步长，并按标准 DOM/DOW 语义运行已发布工作流。
- 看板：手动和定时刷新会重新执行源 SQL，创建新结果并同步更新图表、KPI 和看板，不再只修改时间戳。
- 资源控制：上传、导入、查询、分析、模型参数和时间序列均有行数/单元格/运行时间上限。
- 备份恢复：SQLite Backup API 保证快照一致性，PBKDF2 + AES-256-GCM 保证机密性和完整性，恢复前校验 SHA-256、归档路径、链接成员和 SQLite 完整性。
- 依赖与交付：Python 生产依赖全量锁定并带 hash，已知漏洞已清零；前端离线依赖锁定版本和 SHA-256；容器安装 Microsoft ODBC Driver 18，并以非 root 用户运行。

## 数据库直连边界

- SQLite：可直接使用，查询会话启用 `query_only`、busy timeout 和执行截止。
- PostgreSQL：生产要求 CA 和 `verify-full`，并在会话中强制只读与语句超时。
- MySQL：生产要求 CA 和主机身份验证，并强制只读会话与最大执行时间。
- SQL Server：使用 Microsoft ODBC Driver 18，生产强制 `Encrypt=yes` 和 `TrustServerCertificate=no`，并设置查询超时。实际上线前仍需对目标 SQL Server 版本、CA 链和驱动执行一次现网握手验收。

## 明确不在当前架构中的能力

应用控制面仍使用 SQLite 并通过实例锁禁止同一存储目录的多进程/多副本写入，因此当前是单节点生产架构，不是多活或水平扩展架构。若需 HA，需将控制面迁移到外部事务数据库、对象存储和分布式任务队列，并增加灾备切换测试。
