## 产品与运行基线

阅读了 README、PRODUCT_SCOPE、使用指南、开发指南、架构及截图说明，并核对 Vue 路由、全局状态、公共组件、样式、Flask API、技能发布与成果交付实现。

产品主线是业务人员提问、确认范围、查看分析和依据、交付成果。所有者/编辑者管理数据与资源；模型由所有者配置；分析师可提问及试算；只读成员查看已有内容。保留业务端与后台的职责区别。

运行环境为 macOS、Python 3.12.11、Node 20.19.0、项目已有 `.venv` 与 Node 依赖。通过 `scripts.run_browser_fixture` 启动仅监听回环地址的隔离 Flask 实例，浏览器访问生产构建 `frontend/dist`，不读取或修改用户的 `storage/`。本机沙箱阻止浏览器进程和端口绑定，测试以获准的本地执行方式运行。

演示数据由真实 `POST /api/demo/seed` 载入：24 个月合成销售事实、4,320 行、8 个指标及业务知识。没有配置真实模型、外部业务库、MCP、SMTP 或远端计算平台。

## 功能归属与冗余判断

业务智能体选择与后台智能体编辑、业务指标查看与后台维护、资料库交付文件与数据接入，面向不同任务或阶段，保留各自入口。用户和后台回收站复用同一组件与服务端权限，保留上下文入口。

仅合并同一角色、对象和任务的指标删除操作：从列表逐行删除移到详情，减少危险操作对浏览的干扰。已有删除能力、路由、依赖检查和 API 都保留；原浏览器依赖检查用例同步走详情入口，没有移除失败断言。
