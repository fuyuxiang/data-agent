# 企业分析链路配置

## 已接入正式分析的能力

- 工作空间管理员在“系统管理 → 分析智能体”维护草稿、发布版本与恢复历史版本。业务人员选择已发布智能体后，数据源和知识范围会载入当前会话。Run 保存所用智能体版本和指令快照。
- MCP 服务连接成功后，工作空间所有者须逐个批准可用于正式分析的工具，并为当前会话启用 MCP。工具执行发生在外部服务，其实际读写行为需由管理员核对；返回内容标记为未验证信息，不会自动登记为已核实的数据引用。
- `run_analysis` 在隔离容器内提供 `describe`、`correlation`、`grouped_summary`、`decile`、`ab_test`、`linear_regression`、`kmeans`、`anomaly`、`trend_forecast`。复杂统计方法的参数和假设仍应由分析人员核对。
- 正式发布的 Manifest 可生成 Word、Excel、PPT、PNG；邮件附件与下载使用同一发布版本。访问时重新检查 Run 来源权限及策略版本。

## 数据源行列权限

工作空间所有者可以在“数据资产 → 访问权限”按数据表设置行范围字段、每位成员的可见值，以及全体隐藏字段。规则在文件数据读取与数据库 SQL 查询之前执行，预览、画像、语义查询和正式 Agent 使用相同的数据入口。

API 也接受多规则形式：

```json
{
  "row_policy": {
    "rules": [
      {"table": "sales", "column": "region", "allow": {"user:alice": ["华东"], "role:owner": ["华南"]}}
    ]
  },
  "column_policies": {
    "rules": [
      {"table": "sales", "deny": {"role:analyst": ["customer_phone"]}}
    ]
  }
}
```

`*` 可表示所有主体或所有数据表。同行过滤中的主体值合并，不同行过滤依次取交集；未匹配到可见值的主体读不到对应行。隐藏字段不会进入授权后的数据表。管理员编辑策略后，先前的查询结果、派生数据和正式成果将因策略版本变化而拒绝读取，需重新计算。

数仓来源目前使用连接配置中的服务身份；正式 Agent 会把未限定的表名绑定到所选目录和模式，并拒绝跨目录、跨模式查询。本地行列规则不适用于数仓来源。若需按业务用户执行行列权限，必须在目标仓部署受控视图或受限身份，并验证连接身份、视图授权与查询行为；当前代码尚未提供逐用户数仓身份委派。

## 验证边界

本地回归测试覆盖权限过滤、旧结果撤权、Agent 版本绑定、MCP 授权、审核算法以及交付格式。真实模型、真实业务题集和目标数仓验收按当前安排暂缓；因此这些外部链路的可用性尚未获证实。
