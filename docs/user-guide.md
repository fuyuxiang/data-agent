# 使用指南

[返回 README](../README.md) · [架构设计](architecture.md) · [部署与运维](operations.md)

## 首次使用

配置模型与数据后，即可从工作台开始分析：

1. **连接模型：** 工作空间所有者进入「管理后台 → 模型」，填写 API Key、Base URL 和模型 ID，测试成功后再进行自主分析。
2. **添加数据：** 在「管理后台 → 数据」上传文件或连接数据库；也可以在工作台一键**载入演示数据**。
3. **开始提问：** 回到工作台，用业务语言提问。已有正式指标时优先使用指标定义；探索性问题可直接检索结构并查询授权数据。
4. **核对口径：** 对已发布结果查看来源、口径、证据单元格与核验状态，并人工复核业务解释。
5. **产出成果：** 点击「生成报告 / PPT / 导出 Excel」，文件会存进资料库。
6. **扩展能力：** 在「管理后台 → 技能」调整或新建技能，在「智能体」把它们与数据、指标、知识组合起来。

## 智能体与技能

智能体的草稿和发布版本独立保存。编辑、保存或回滚草稿后，点击发布才会切换用户使用的配置。被草稿或当前发布版本引用的知识文档，需先解除引用并发布修改，再删除或停用。

分析、归因、预测、文件分析和报告技能带有通用方法参考，Agent 按需读取相关章节。管理员可在技能的「方法参考」中维护文档，参考内容随技能版本、克隆及导入导出保存。方法说明不能扩展数据权限或执行未审核代码，也不预设业务系统、表名或字段。

## 结果核验与交付

报告中的关键指标绑定本次查询的具体单元格，数值由服务端读取；发现中的显式数字需要能在引用结果中核对，事实与推测分开呈现。正式指标解释保留查询时的定义、公式、单位和版本；探索口径标明待核对。未经评估的业务准确性保留未评估状态。报告校验失败时需修正后才能发布。

报告导出复用已发布的数据与结论，不重新调用模型或查询数据源。Word、PPT、HTML 与 Excel 保留相同的发现、建议、口径和局限；Excel 对多份结果分别建立工作表，网页报告内嵌图表图片，可离线查看。长结论在 PPT 中分页，文档中的部分行列预览会明确提示完整数据位于 Excel。

## 分析记录与回收站

分析可以终止，也可以在结束后移入回收站。外部计算任务在确认停止后显示“已取消”；连接失败时会显示原因并自动重试。删除分析后，原会话中的提问与回答隐藏，资料库成果和执行记录继续保留；误删内容可从侧栏「回收站」恢复。回收站沿用原有权限，个人分析仅对本人可见；永久删除需要再次确认。

## 演示数据

在工作台点击「使用演示数据」或显式调用 `POST /api/demo/seed` 后，系统创建以载入当月为终点的 24 个月**合成**零售销售事实表（区域 × 城市 × 品类 × 渠道）、8 个正式指标和 4 条业务知识。该数据仅用于体验产品。同一月份首次载入的数据可复现；新工作空间在不同月份首次载入时，时间窗口会随之移动，已有工作空间重复载入保持原数据。可用以下问题体验分析流程：

```text
本月销售额是多少？
华东销售同比怎么样？
哪个城市下降最多？
为什么华东销售下降？
哪些商品表现异常？
预测下个月销售额。
生成经营分析报告。
生成经营分析 PPT。
```

合成数据中的华东最近几个月设有同比下滑，且可按品类与渠道定位变化贡献；这支持展示归因分析流程，不能据此宣称已识别真实经营因果。
